Plotting (``dv.plotting``)
==========================

Plot types. Every class follows the two-phase pattern: data and computation parameters at construction, styling and rendering in ``plot()``.

Imported as ``diive.plotting``, reached as ``dv.plotting`` after ``import diive as dv``.

.. The heatmap-family classes inherit their rendering and formatting methods
.. from HeatmapBase; without :inherited-members: only __init__ is documented.
